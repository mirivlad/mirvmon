# MirvMon v0.5.4.5

## Управление графиками

- Средняя кнопка мыши теперь перетаскивает график серверных метрик влево и вправо по временной шкале.
- Колесо мыши по-прежнему управляет масштабом.
- Во время удержания средней кнопки курсор показывает режим перетаскивания, а live-refresh не заменяет активный canvas.
- После отпускания график продолжает обычный live-scroll с сохранённым масштабом.
- В интерфейс добавлена короткая подсказка по управлению графиком.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.4.5` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД нет.
- Agent protocol не изменён; переустанавливать агенты не требуется.
