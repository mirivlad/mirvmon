# MirvMon v0.5.4.2

## Исправление живых метрик

- Исправлен редкий визуальный race Chart.js при автоматическом обновлении графиков сервера.
- Сохранённый zoom/pan теперь не только восстанавливается во внутреннем состоянии Chart.js, но и сразу отрисовывается на canvas.
- После live-refresh больше не требуется клик или движение мыши, чтобы вернуть выбранный масштаб.
- Стартовая анимация live-графиков отключена, чтобы она не перерисовывала восстановленный viewport поверх актуального состояния.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.4.2` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД нет.
- Agent protocol не изменён; переустанавливать агенты не требуется.
