# MirvMon v0.9.6 — PHP2Shell security update

## Security

- Update the production FrankenPHP base image to `1.13.2-php8.5-trixie`, which includes PHP `8.5.12` with fixes for `CVE-2026-109618` and `CVE-2026-109619` (PHP2Shell) and upstream FrankenPHP security fixes.
- Reject container builds that contain PHP older than `8.5.12`.

## Compatibility

No database migrations, API changes, new environment variables, or agent protocol changes. Agents do not require an update.

## Deployment

Use `ghcr.io/mirivlad/mirvmon:0.9.6` after the CI/release workflow publishes and verifies its multi-architecture manifest. In Portainer, re-pull and redeploy the application container while preserving `app_data` and `db_data` volumes. Verify PHP with `docker exec <container> php -r 'echo PHP_VERSION, "\n";'`.
