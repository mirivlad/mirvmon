# MirvMon v0.5.2

## Уведомления

- Исправлено имя сайта в website alerts: вместо `unknown` уведомление теперь содержит реальное название сайта.
- Графики уведомлений больше не ограничены только числовыми `metric_*` алертами серверов.
- Offline-события серверов получают график доступности за последний час.
- HTTP, assertion и performance-события сайтов получают соответствующий график доступности, успешности проверки или времени ответа, если накоплено достаточно данных.
- Для числовых метрик серверов сохранён прежний график за последний час с линией сработавшего порога.
- Если временного ряда недостаточно или PNG не удалось построить, уведомление по-прежнему отправляется текстом.

## README и скриншоты

- README сокращён и сфокусирован на возможностях, быстром старте, мониторинге сайтов, уведомлениях и ссылках на подробную документацию.
- Галерея заменена на три реальные отдельные картинки: главная, метрики сервера и метрики сайта.
- Удалены старые составные и дублирующиеся скриншоты.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.2` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД в этом релизе нет; дополнительных сервисов и портов не добавлено.
