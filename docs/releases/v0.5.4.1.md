# MirvMon v0.5.4.1

## Исправления интерфейса

- Упрощены заголовки основных страниц: убраны дублирующие надзаголовки, сокращены описания и выровнены иконки с основной навигацией.
- На странице агентов исправлены отступы заголовка таблицы и перенос кнопки перехода к агенту.
- Убрано служебное сообщение о локальной retry-очереди агента.
- На странице настроек уведомлений кнопка перехода к очереди перенесена сразу под заголовок, а нижняя информационная плашка удалена.

## Живые метрики

- Исправлено сохранение zoom/pan на графиках сервера при автоматическом обновлении данных.
- Пользовательский viewport теперь запоминается сразу после завершения zoom/pan и восстанавливается по timestamp после прихода свежих точек.
- `Reset zoom` очищает сохранённый viewport и возвращает график в обычный live-режим.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.4.1` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД нет.
- Agent protocol не изменён; переустанавливать агенты не требуется.
