# MirvMon v0.7.6

## What changed

- Fixed a UI regression where the literal characters `\\n` were rendered above application pages.
- The regression affected both the main application layout and the login/setup layout.
- Added a contract test so literal escaped newline sequences cannot silently reappear in shared document heads.

## Upgrade

Use:

`ghcr.io/mirivlad/mirvmon:0.7.6`

No database migration, agent protocol change, agent reinstall, new Compose service or new configuration is required.
