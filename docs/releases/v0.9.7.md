# MirvMon v0.9.7 — security-only PHP2Shell hotfix

This supersedes the unpublished v0.9.6 candidate, which was not released because its CI contract tests still expected outdated runtime and documentation pins.

## Security
- FrankenPHP updated to **1.13.2**; embedded PHP **8.5.12** closes **CVE-2026-109618** and **CVE-2026-109619**.
- Runtime guard prevents publishing images with vulnerable PHP.
- Release/version and runtime contract tests updated.

## Compatibility
No migrations, application API or agent protocol changes. Existing agents remain compatible.

## Upgrade
Use `ghcr.io/mirivlad/mirvmon:0.9.7` after GHCR publication succeeds, and re-pull/redeploy your Portainer app while keeping `app_data` and `db_data`. Verify `php -r 'echo PHP_VERSION;'` inside the running container is at least 8.5.12.
