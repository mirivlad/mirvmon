# MirvMon v0.9.5

## Что исправлено

- Кнопка профиля пользователя в navbar теперь нормально видна в обычном состоянии: имя пользователя отображается белым, а у кнопки есть заметный светлый контур ещё до наведения курсора.
- Для profile dropdown явно заданы Bootstrap button variables для normal, hover, focus, open и active states. Это исключает повторение регрессии из-за каскада Bootstrap.
- Добавлен UI contract test, который фиксирует наличие явных цветов текста и рамки у кнопки профиля.

## Совместимость

Схема БД, agent protocol и backend API не меняются. Новых Compose services и обязательных переменных окружения нет. Обновление агентов не требуется.

## Обновление

Используйте `ghcr.io/mirivlad/mirvmon:0.9.5`. Достаточно обычного re-pull/redeploy image.
