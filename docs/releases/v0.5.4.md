# MirvMon v0.5.4

## Обзор парка агентов

- Добавлен отдельный раздел **«Агенты»** для эксплуатации всего парка: текущие и устаревшие версии, состояние связи, ход обновлений, ошибки и случаи, требующие ручного вмешательства.
- Добавлены фильтры, поиск, распределение версий и быстрый переход к управлению конкретным агентом.
- Обзор использует уже существующие agent metadata, last contact, platform и update state; отдельный fleet protocol или worker не добавлялся.

## Живой операционный интерфейс

- Основные operational-экраны теперь обновляют состояние без ручного reload: серверы, сайты, группы, активные инциденты, очередь уведомлений и самодиагностика MirvMon.
- Polling приостанавливается в скрытой вкладке браузера и не перезаписывает блок, с которым пользователь прямо сейчас взаимодействует.
- Фоновые live-запросы не потребляют flash-сообщения пользовательских действий.
- Детальная страница сервера оптимизирована: вкладки `agent`, `events` и `services` не строят исторические metric series при каждом live-refresh.

## Живые метрики сервера

- Графики сервера автоматически получают свежие данные каждые 30 секунд.
- Незумированный график продолжает двигаться вместе с выбранным периодом.
- При zoom/pan MirvMon сохраняет границы по timestamps и восстанавливает тот же временной участок после прихода новых данных.
- `Reset zoom` возвращает график в обычный live-режим; custom range остаётся фиксированным.
- Вместе с графиками обновляются последние значения, availability и дисковые карточки.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.4` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД нет.
- Agent protocol не изменён; переустанавливать агенты для перехода на v0.5.4 не требуется.
