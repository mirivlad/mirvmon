# MirvMon v0.5.4.3

## Исправление live zoom

- Wheel/pinch zoom на графиках сервера теперь сохраняет масштаб, но остаётся в live-режиме: свежие точки продолжают появляться после автоматического обновления.
- Pan и drag-zoom по-прежнему фиксируют выбранный исторический диапазон до `Reset zoom`.
- Live-refresh больше не останавливается из-за обычного focus кнопки, ссылки или canvas; пауза сохраняется только для редактируемых `input/select/textarea/contenteditable`.
- Сохранённый viewport после refresh сразу отрисовывается без дополнительного движения мыши.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.4.3` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД нет.
- Agent protocol не изменён; переустанавливать агенты не требуется.
