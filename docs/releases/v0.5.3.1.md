# MirvMon v0.5.3.1

## Исправление массового обновления агентов

- Плашка массового обновления на странице серверов теперь обновляется вместе с живыми статусами агентов, а не остаётся снимком момента нажатия кнопки.
- Прогресс показывает, сколько агентов завершили обновление, ожидают запуска, обновляются сейчас, завершились ошибкой или требуют ручного обновления.
- После завершения операции плашка остаётся в итоговом актуальном состоянии, например `завершено 11 из 11`, вместо устаревшего `Запланировано: 11`.
- Цвет плашки отражает состояние операции: процесс, успешное завершение, необходимость ручного вмешательства или ошибка.

## Обновление

- Для Docker/Portainer используйте `ghcr.io/mirivlad/mirvmon:0.5.3.1` и выполните обычный re-pull/redeploy stack.
- Изменений схемы БД нет.
- Agent protocol не изменён; переустанавливать или обновлять агенты ради этого hotfix не требуется.
